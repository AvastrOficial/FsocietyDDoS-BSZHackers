## 📝 Descripción

> **Fsociety V3** es una aplicación gráfica escrita en **Python** que permite realizar **pruebas de estrés** de manera **controlada** contra un sitio web específico.

La herramienta utiliza **múltiples direcciones IP públicas**, obtenidas de diversas fuentes en línea, para **simular tráfico distribuido**, permitiendo observar el comportamiento del servidor bajo carga.

## 🔧 Funciones Avanzadas Incluidas

- 🔄 Rotación automática de User-Agents
- 🕵️ Simulación de IPs mediante headers HTTP
- 🌍 Obtención dinámica de proxies públicos
- 🔌 Conexiones persistentes (Keep-Alive)
- ⚡ Ejecución por lotes con concurrencia controlada
- 📈 Cálculo de peticiones por segundo (RPS)
